# Manus 指示文

`schedule.csv` と動画ファイル（`reel-001.mp4` 〜）をManusにアップロードしたうえで、
以下をそのまま貼る。**バッチ1（W01–06）とバッチ2（W07–13）に分けて2回実行する。**

---

## バッチ1: Week 01–06（2026-09-21 〜 2026-11-01 / 42本）

```
Instagramのビジネスアカウントに、リール動画の予約投稿をまとめて登録してください。

【入力ファイル】
- schedule.csv … 投稿データ（91行）。今回は week 列が 1〜6 の行だけを対象にしてください。
- reel-001.mp4 〜 reel-042.mp4 … 投稿する動画。

【CSVの列の使い方】
- media_file   … アップロードする動画ファイル名
- date + time  … 予約日時。タイムゾーンは timezone 列（Asia/Seoul）で解釈してください。
- caption_full … キャプション欄にそのまま貼り付ける全文です。本文・CTA・ハッシュタグが
                 すでに1つのテキストになっています。加工・要約・翻訳は一切しないでください。
- title, hook, script_file, status … 管理用のメモです。投稿には使いません。

【手順】
1. Instagramのプロアカウントにログインし、リールの予約投稿画面を開いてください。
2. week 列が 1〜6 の行を no 列の昇順で処理します。
3. 各行について、media_file の動画をアップロードし、caption_full をキャプションに貼り、
   date と time（Asia/Seoul）で予約日時を設定して、予約として保存してください。
4. 10件ごとに1〜2分の間隔を空けてください。連続で大量に投入すると自動化として
   遮断されることがあります。
5. 1件でも失敗したら、そこで止めて報告してください。飛ばして先に進まないでください。

【重要な制約】
- キャプションは一字一句そのまま使ってください。絵文字の追加も削除もしないでください。
- 予約日時が過去になる行があれば、投稿せずにその行番号を報告してください。
- 予約可能な先行日数の上限に達した場合は、そこまでの登録件数と最後に成功した no を
  報告して停止してください。残りは次回に回します。
- 予約は「保存」までです。即時公開は絶対にしないでください。

【完了報告に含めてほしいもの】
- 予約登録に成功した no の一覧
- 失敗した no と、その理由
- 登録された最初と最後の予約日時
```

## バッチ2: Week 07–13（2026-11-02 〜 2026-12-20 / 49本）

上の指示文の以下2箇所を差し替えて、バッチ1の完了後に実行する。

- `week 列が 1〜6` → **`week 列が 7〜13`**（2箇所）
- `reel-001.mp4 〜 reel-042.mp4` → **`reel-043.mp4 〜 reel-091.mp4`**

バッチ1で先行日数の上限に当たって途中停止した場合は、バッチ2の冒頭に
「no が ○○ 以降の行を対象にしてください」を追記して範囲を調整する。

## Manusに渡す前のチェック

- [ ] 対象週の動画がすべて揃っていて、ファイル名が `schedule.csv` の `media_file` と一致している
- [ ] Instagramがプロアカウント（ビジネス／クリエイター）になっている
- [ ] 韓国語アカウントに切り替わっている（日本語アカウントに投稿しないよう、Manusに開かせる前に確認）
- [ ] `caption_full` の文字数に問題がない（最長380字。上限2,200字に対し余裕あり）
