## 第2部　構造による分類（身体性抜き）

地域を横断すると、呪いは「何を介して働くか」でおよそ12型に分けられる。

| # | 型 | 代表例 |
|---|---|---|
| 1 | **似姿・代替物を介す** | 藁人形、呪詛文書、巫蠱の人形、マクルー、打小人、ンキシ |
| 2 | **身体の断片を介す** | 髪・爪、叫魂の辮髪、ウィッチボトル |
| 3 | **まなざし** | 邪視（アイン、ナザル、マル・デ・オホ、baskania） |
| 4 | **物質を介す** | 蠱毒、ゾンビ・パウダー、ソタの苦い水 |
| 5 | **禁忌・制約を課す** | ゲシュ、タプ、物忌み、方違え、穢れ |
| 6 | **霊的存在を送る・憑かせる** | 式神、犬神、ジン、ディブク、生霊、怨霊 |
| 7 | **血統で継承される** | 憑きもの筋、アザンデのmangu、家系の呪い |
| 8 | **自分にかける（誓約・神判）** | 起請文、盟神探湯、苦い水、誓約 |
| 9 | **共同体から切り離す** | 破門、ニーズ、村八分、スティグマ |
| 10 | **予言・宣告する** | ボーン・ポインティング、医療ヘックス、自己成就予言 |
| 11 | **物・場所に宿る** | 呪われた品、墓の呪い、事故物件 |
| 12 | **集団に伝染する** | 舞踏病、コロ、叫魂、魔女狩り |

言葉（呪文・名前）は1〜12の多くに添えられるが、主役でない型のほうが多い。

## 第3部　身体性からの分析

### 発見1：世界中の呪いが「縛る」という動詞に集まる

文化圏を越えて、呪いの語彙は驚くほど「縛る・固める・動けなくする」に集中している。

- ギリシアの katadesmos、ラテン語の defixio：「縛りつける」「釘で留める」
- フランスの ligature：結び目で縛る
- タントラの stambhana：麻痺させる、不動にする
- 日本語の「呪縛」「金縛り」
- 釘：丑の刻参り、呪詛板、ンキシ・ンコンディ。いずれも「打ち込んで固定する」

**解釈**：呪いの原型的なイメージは「身体が固まって動けなくなること」。これは大沼理論の「硬化」「閉ざされ」と同じ現象を、別の時代の言葉で記述したものと読める。

### 発見2：呪いは身体に4つのことをする

12型を身体への作用で整理し直すと、4つの動きに集約できる。

| 作用 | 何が起きるか | 該当する型 | 大沼理論との対応 |
|---|---|---|---|
| **縛る**（固定） | 身体が固まり動けなくなる | 1 似姿、3 まなざし、5 禁忌、8 自己呪詛 | 硬化、ゆるむ能力の喪失 |
| **抜く**（剥離） | 魂・感覚が身体から離れる | 2 身体の断片（叫魂）、ススト、取り替え子 | 内受容感覚の途絶、差異を知覚する能力の喪失 |
| **入れる**（侵入・上書き） | 自分でないものが身体を動かす | 4 物質、6 憑依、10 予言、ゾンビ | 外部の予測による上書き。主体性の喪失 |
| **移す**（伝染・継承） | 身体の状態が他者へ移る | 7 血統、11 物・場所、12 集団 | 模倣による硬さの継承。世代間連鎖 |

9「共同体から切り離す」はこの4つすべてを引き起こす土台として別枠に置ける。触れられない、見られ続ける、居場所がない、という状態は、身体を慢性的な防御モードに置く。

### 発見3：型ごとの身体メカニズム（仮説）

| 型 | 身体で何が起きているか（仮説） |
|---|---|
| まなざし（邪視） | 見られていると感じると、身体は警戒して固まる。邪視信仰は「見られることの身体負荷」を言語化したものと読める。 |
| 禁忌・物忌み・方違え | 行動範囲や動きそのものを制限する。身体の選択肢を減らし、動きを単調にする（組織分化の喪失）。 |
| 予言・宣告 | 脳の「予測」が先に書き込まれ、身体がそれに合わせて反応する（内受容感覚推論への介入）。ボーン・ポインティングとノセボは同じ構造。 |
| 自己呪詛・神判 | 嘘をつく緊張で口が渇く、手が震える。身体が「真実を語る装置」として使われる。逆に言えば、恐怖が身体を確実に変えることを、昔の人は知っていた。 |
| 憑依 | 本人の意志と身体の動きが切り離される体験。解離として読める。 |
| 魂抜け（ススト、叫魂） | 強い驚きのあと、身体感覚が薄れる。「自分がここにいない」感じ。 |
| 血統（mangu、憑きもの筋） | アザンデでは妖術が「腹の中の物質」として遺伝するとされた。身体に宿り、本人も知らずに作動する呪いという考え方は、無自覚に受け継がれる身体の癖や緊張に近い。 |
| 集団伝染（舞踏病、コロ） | 身体の状態は模倣で広がる。恐怖も緊張も、言葉より速く伝染する。 |
| 金縛り・マーラ | 睡眠麻痺という生理現象を、世界中が「何かに乗られて動けない」と解釈した。身体の不可解な固まりを、外部の悪意で説明する典型例。 |

### 発見4：解呪の技法も身体的である

呪いが身体を縛るなら、世界の解呪・祓いの技法も身体に働きかけるものが多い。

| 解呪の技法 | 身体の動作 | 大沼理論の実践との対応 |
|---|---|---|
| **撫物（なでもの）**（大祓など） | 人形（ひとがた）で身体を撫で、息を吹きかけ、川に流す | **さする** |
| **魂振り（たまふり）**、布瑠の言「ふるべ ゆらゆら」 | 振る、揺らすことで魂を活性化させる | **ゆする** |
| 禊・水垢離 | 水で身体を清める | 皮膚感覚の更新 |
| ルクヤ | 唱えた息を身体に吹きかける | 呼吸と触覚 |
| 大幣を振る祓い | 揺れるものを身体の周囲で振る | ゆする |
| 護符を身に着ける | 身体の境界に「守り」を置く | 皮膚＝自他の境界の再確認 |
| 舞・踊り（シャーマニズムのトランス、クッ） | リズムで身体を揺らし続ける | ゆする、ゆるむ |

**解釈**：「さする」「ゆする」は思いつきの技法ではなく、人類が古くから「呪いを解く」ために使ってきた身体技法と同じ系譜に置ける。本書の終盤で、大沼理論の実践を「古来の解呪の再発見」として位置づける根拠になる。

## 本書の骨格候補（ここまでのまとめ）

1. 呪いは世界中にある（第1部のカタログから代表例）
2. 呪いの共通語は「縛る」である（発見1）
3. 呪いは身体を「縛る・抜く・入れる・移す」（発見2・3）
4. 現代の呪いも同じ4つの動きをしている（椅子、通知、数値、評価のまなざしなど。前回の議論）
5. 解呪は身体から：撫でる・振る（発見4）→ さする・ゆする → 適応的身体基盤
